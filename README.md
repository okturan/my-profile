# Early Personal Profile Page

> **Status:** historical HTML/CSS learning exercise. This page preserves an early personal-profile card from the Le Wagon bootcamp; it is not Okan's current professional portfolio.

## Live exercise

[Open the GitHub Pages deployment](https://okturan.github.io/my-profile/)

## What it demonstrates

- A responsive stack of card components.
- Local image presentation and rounded profile styling.
- Web-font and icon integration.
- Basic social-link and call-to-action styling.
- Deployment of a dependency-free page through GitHub Pages.

## Run locally

No dependencies or build step are required:

```bash
open index.html
```

## Scope

The family, camera, and dad-joke copy is intentionally personal and retained as part of the learning artifact. The current engineering portfolio lives on [the GitHub profile](https://github.com/okturan); this repository is deliberately unpinned and should not be mistaken for the current profile front door.

The repository has no package, release stream, or CI workflow because its only runtime is the static Pages deployment. It is archived as learning history, and no further development is planned.
